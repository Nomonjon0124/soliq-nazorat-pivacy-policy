Privacy Policy

Last updated: October 5, 2026

This policy applies to the current version of Soliq Nazorat. The application uses preloaded sample information and has no feature for sending information to an external server.

1. Scope of this policy

Soliq Nazorat is an application for displaying tax risk signals, analysis, actions and reports. This document explains how information is used within the application. It does not cover the separate data practices of the download platform or the hosting service where this HTML page is published.

2. Information used

The current version has no registration or sign-in feature. The application does not automatically collect your name, phone number, email address, password, device identifier or location.

  • Sample information: profiles, organizations, tax signals, evidence and analysis text are bundled with the application as sample content; they are not obtained from your device.
  • Text you enter: text entered into a document draft is processed in your device’s memory while the application is running.
  • Session changes: the language selection, signal status, document drafts and action history are held temporarily in memory.

The “Add evidence” action currently creates a sample file record. It does not select, read or upload an actual file from your device.

3. How information is used

Temporary information is used to apply your language selection, display document drafts, update signal status and show action history. It is not used for advertising, user tracking or building marketing profiles.

4. External services and sharing

The current application has no remote API, advertising, usage analytics or integration that sends crash reports to an external service. The application does not send or sell text you enter to the developer or third parties.

The “AI analysis” and recalculation features use sample logic. Information is not sent to an external artificial intelligence service.

The operating system or app store may process diagnostic information under its own settings and policies. This is separate from data collection within the application.

5. Retention and deletion

Text you enter and session changes are not permanently written to a database, file or cloud service. This temporary information is not retained after the application process ends. Moving the application to the background alone may not end the process.

To clear temporary information, fully close and restart the application. Bundled sample information is displayed again when the application is reopened. There is no account deletion feature because no user account is created on a server.

6. Device permissions and tracking

The current version does not request access to the camera, microphone, contacts, location or device files. The application has no tracking SDKs or cookie-based tracking mechanisms.

This policy’s HTML file does not load external scripts, fonts or tracking resources. If the page is hosted online, the hosting service may record IP addresses and access times under its own policy.

7. Information security

Do not enter actual personal, tax or confidential work information, or passwords, into the application. Protecting your device with a screen lock is recommended. No software or device can guarantee absolute security.

8. Children’s privacy

The application is intended to demonstrate professional use scenarios and is not directed at children. The current version has no features specifically designed to collect information from children.

9. Changes to this policy

If server connectivity, authentication, persistent storage, actual file uploads, analytics or external AI services are added, this policy must be updated to reflect the new data flows. The updated text will include the revision date.

10. Operator and contact

Privacy contact: raqamlinazorat3@gmail.com

Soliq Nazorat — приложение для отображения сигналов налоговых рисков, анализа, мер и отчётов. Этот документ объясняет, как используются данные внутри приложения. Он не охватывает отдельные правила обработки данных платформы загрузки приложения или хостинга, на котором размещена эта HTML-страница.

В текущей версии нет регистрации и входа в учётную запись. Приложение не собирает автоматически ваше имя, номер телефона, адрес электронной почты, пароль, идентификатор устройства или местоположение.

  • Примерные данные: профили, организации, налоговые сигналы, доказательства и тексты анализа включены в приложение как образцы; они не извлекаются с вашего устройства.

Действие «Добавить доказательство» сейчас создаёт запись о примерном файле. Оно не выбирает, не читает и не загружает настоящий файл с вашего устройства.

Временные данные используются для применения выбранного языка, отображения проекта документа, обновления статуса сигнала и показа истории действий. Они не используются для рекламы, отслеживания пользователей или создания маркетинговых профилей.
